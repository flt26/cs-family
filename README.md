# موقع كروت عيلة دفعة CS

موقع صغير: كل واحد يدوس على اسمه → الكارت يتضاف على Apple Wallet.

## الرفع على Vercel

```bash
cd site
npx vercel --prod      # أو اربط المجلد من vercel.com
```
بعدها من إعدادات المشروع ← **Domains** اربط الدومين بتاعك.

## قبل الرفع — حط الكروت

بعد ما توقّع الكروت (من ملف `CSFUE-Wallet-Cards.zip` ← `sign.sh`)، انسخ ملفات
`signed/001.pkpass … 045.pkpass` جوه مجلد **`passes/`** بنفس الأرقام.

الأرقام موجودة في `index.csv` جنب كل اسم.

## ملحوظات

- `vercel.json` بيظبط الـ`Content-Type` الصح للـpkpass (من غيره الآيفون مش هيفتحه)
- الصفحة فيها خانة بحث عشان الـ٤٥ اسم
- `assets/tree.png` هي الشجرة الكاملة اللي بتظهر تحت
